## 1. 模型矩阵

RDL-Dreams 管线使用两个 NVIDIA Cosmos 模型，分别承担**生成**和**评判**角色：

| 维度 | Cosmos Predict 2.5 | Cosmos Reason 2 |
|------|--------------------|-----------------|
| **架构** | 扩散 Transformer (DiT) + VAE | 视觉语言模型 (VLM) |
| **基座** | 自研 Cosmos VAE + DiT | Qwen3-VL (7B) |
| **参数量** | 2B ~ 14B | 8B |
| **输入** | 图像/视频帧 + 文本 Prompt | 视频 + 评分 Prompt |
| **输出** | 未来视频帧序列 (轨迹) | 物理合理性评分 (1-5) |
| **模式** | Video2World / Image2World | 零样本 / SFT |
| **许可** | NVIDIA Open Model License | NVIDIA Open Model License |

## 2. Cosmos Predict 2.5 — 视频世界模型

### 2.1 架构概览

```
Predict 2.5 Video2World 推理流程
──────────────────────────────────────────────────────

  ┌─────────┐    ┌───────────┐    ┌─────────┐
  │ 初始帧    │    │ VAE 编码器 │    │ 潜在表示 │
  │ (H×W×3) │───→│ (8×压缩)   │───→│ z_t     │
  └─────────┘    └───────────┘    └─────────┘
                                       │
  ┌─────────┐                          ▼
  │ Prompt   │    ┌───────────┐    ┌─────────┐    ┌───────────┐    ┌─────────┐
  │          │───→│ 文本编码器 │───→│ DiT     │───→│ VAE 解码器 │───→│ 未来帧  │
  └─────────┘    └───────────┘    │ 去噪    │    └───────────┘    │ (视频)  │
                                  └─────────┘                    └─────────┘
```

### 2.2 关键组件

| 组件 | 说明 |
|------|------|
| **Cosmos VAE** | 视频变分自编码器，对视频帧进行 8× 空间压缩 + 时间压缩，将像素空间映射到低维潜在空间 |
| **扩散 Transformer (DiT)** | 在潜在空间中进行多步去噪，融合文本条件（cross-attention）和视觉条件（concat），生成未来帧的潜在表示 |
| **文本编码器** | 将语言 Prompt 编码为条件嵌入，注入 DiT 的交叉注意力层 |

### 2.3 Video2World 模式

Video2World 是 Predict 2.5 的核心模式，区别于 Image2World：

| 模式 | 输入 | 输出 | 适用场景 |
|------|------|------|---------|
| **Image2World** | 1 张静止图像 | 未来 N 帧 | 单帧条件生成 |
| **Video2World** | K 帧历史视频 | 未来 N 帧 | **轨迹预测/动作推理** ✅ |

对于零售抓取场景，Video2World 的优势在于：
- 可输入机械臂运动的前几帧作为历史上下文
- 模型学习物理运动趋势，生成更连贯的后续轨迹
- 适合"给定当前状态 → 预测完整动作序列"的范式

### 2.4 模型规模选择

| 规模 | 参数量 | 显存需求 (推理/batch=1) | 显存需求 (训练/batch=1) | 适用场景 |
|------|--------|------------------------|------------------------|---------|
| **2B** | ~20 亿 | ~40 GB | ~60 GB | 默认选择，训练效率高，迭代快 |
| **14B** | ~140 亿 | ~80 GB | ~200+ GB | 更高质量，需更大算力 |

推荐从 2B 起步，在零售数据上完成快速迭代后，必要时升级至 14B。

### 2.5 训练配置

```python
# cosmos_predict2/_src/predict2/configs/video2world/config.py
# 核心配置来自: predict2_video2world_training_2b_groot_gr1_480

        workers=4,
    ),
)
```

## 3. Cosmos Reason 2 — 物理合理性 Critic

### 3.1 架构概览

```
Reason 2 评分流程
──────────────────────────────────────────────────────

  ┌─────────┐    ┌───────────┐    ┌───────────────────┐
  │ 视频输入  │    │ 视觉编码器 │    │ Qwen3-VL (7B)     │
  │ (N 帧)   │───→│ (ViT)     │───→│                   │
  └─────────┘    └───────────┘    │  视频 → 语言投影   │
                                  │                   │
  ┌─────────┐                     │  物理常识推理       │
  │ 评分     │    ┌───────────┐    │                   │
  │ Prompt  │───→│ 文本编码   │───→│                   │
  └─────────┘    └───────────┘    └──────────┬────────┘
                                              │
                                              ▼
                                    ┌───────────────────┐
                                    │ 评分: 1 / 2 / 3 /  │
                                    │ 4 / 5              │
                                    └───────────────────┘
```

### 3.2 关键特性

| 特性 | 说明 |
|------|------|
| **基座模型** | Qwen3-VL (7B 参数视觉语言模型) |
| **推理能力** | 思维链 (Chain-of-Thought) 物理常识推理 |
| **评分粒度** | 1-5 整数分，对应"完全违反物理"到"完全符合物理" |
| **零样本支持** | ✅ 开箱即用，无需训练数据 |
| **SFT 微调** | ✅ 支持在 VideoPhy-2 等数据集上微调提升准确率 |
| **RL 训练** | ✅ 支持强化学习 (RL) 训练，适合高质量但稀缺数据的场景 |

### 3.3 评分维度

Reason 2 从 4 个维度评估视频物理合理性：

| 维度 | 评估内容 | 零售场景示例 |
|------|---------|-------------|
| **物体行为** | 刚体不变形、液体自然流动 | 麦片盒被抓起时不应变形 |
| **运动与力** | 重力、惯性、动量守恒 | 商品被放入购物车后应自然下落 |
| **物体交互** | 无穿透、碰撞反应合理 | 机械爪不应穿透商品表面 |
| **时序一致性** | 帧间无突变 | 机械臂运动轨迹连续无跳变 |

### 3.4 Critic 评分标准 (5 分制)

```
┌─────┬──────────────────────────────────────────────────────┐
│ 5 分 │ 完美 — 完全符合物理，无任何违反                           │
│ 4 分 │ 良好 — 大部分符合物理，仅有微小瑕疵 ✅ 筛选阈值              │
│ 3 分 │ 中等 — 大体正确但存在明显不一致                           │
│ 2 分 │ 较差 — 少数元素符合，多数违反                                 │
│ 1 分 │ 很差 — 大量物理规则违反，不可用                                │
└─────┴──────────────────────────────────────────────────────┘
```

### 3.5 零样本 vs SFT

| 策略 | 优点 | 缺点 | VideoPhy-2 准确率 |
|------|------|------|------------------|
| **零样本** | 即时可用、无需数据 | 准确率有上限 | ~65% (Reason 2 8B) |
| **SFT** | 显著提升准确率 | 需 3.4k VideoPhy-2 训练数据 + GPU 训练 | ~80%+ (预估提升 15-20%) |
| **RL** | 更灵活，适应多样化场景 | 需高质量标注数据 | 取决于数据 |

## 4. 模型间协作机制

### 4.1 Best-of-N 拒绝采样

```
for each retail_grasp_scene:
    N = 5                            # 每个场景生成 5 条候选轨迹
    candidates = []
    for i in range(N):
        video = Predict2.5.generate(prompt, image, seed=i)
        candidates.append(video)

    scored = [Reason2.score(v) for v in candidates]

    # 筛选策略
    best = argmax(scored)            # 方式 1: 选最高分
    good = [v for v, s in scored if s >= 4.0]  # 方式 2: 选所有 >= 4.0 的

    use best (or all good) for downstream task
```

### 4.2 模型解耦带来的灵活性

- **独立部署**：Predict 2.5 和 Reason 2 可部署在不同 GPU 节点
- **独立迭代**：可以独立更换生成模型或评判模型（如从 2B → 14B Predict，或 Reason 2 → 未来更强 Critic）
- **成本优化**：可根据需要调整 N 值平衡质量和计算成本

## 5. 零售场景适配

### 5.1 对 Predict 2.5 的要求

| 要求 | 说明 |
|------|------|
| 理解商品名称 | 训练数据中需包含 cereal box / bottled water / shampoo 等物体 |
| 理解货架空间 | 模型需生成从货架层到目标位置的有效运动路径 |
| 机械臂运动学 | 训练时需包含与实际部署一致的机器人末端执行器视觉信息 |

### 5.2 对 Reason 2 的要求

| 要求 | 说明 |
|------|------|
| 商品完整性 | 被抓商品不应发生变形或物理违反 |
| 碰撞检测意识 | 机械臂不与货架发生穿透 |
| 重力行为意识 | 商品放入购物车/购物篮后应呈现自然下落 |
