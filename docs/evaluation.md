## 1. 评估维度

RDL-Dreams 从 **视频质量** 和 **物理合理性** 两个维度评估生成轨迹：

```
评估体系
═══════════════════════════════════════════════════

  维度 A: 视频质量                    维度 B: 物理合理性
  ┌─────────────────┐                ┌─────────────────┐
  │ FID (Frechet     │                │ Critic 准确率    │
  │  Inception Dist) │                │ (Accuracy)      │
  │                  │                │                 │
  │ FVD (Frechet     │                │ Critic 相关系数   │
  │  Video Dist)     │                │ (Correlation)    │
  │                  │                │                 │
  │ IS (Inception    │                │ 评分分布          │
  │  Score)          │                │ (Score Dist)     │
  └─────────────────┘                └─────────────────┘
          │                                  │
          ▼                                  ▼
  ┌─────────────────────────────────────────────────┐
  │              综合评估结论                         │
  │  视频质量良好 + 物理合理性高 → 可用于下游任务      │
  └─────────────────────────────────────────────────┘
```

## 2. 视频质量指标

### 2.1 指标说明

| 指标 | 全称 | 衡量内容 | 越低越好? |
|------|------|---------|----------|
| **FID** | Fréchet Inception Distance | 生成帧与真实帧的特征分布距离 | ✅ 越低越好 |
| **FVD** | Fréchet Video Distance | 生成视频与真实视频的时序特征分布距离 | ✅ 越低越好 |
| **IS** | Inception Score | 图像的清晰度和多样性 | ❌ 越高越好 |
| **PSNR** | Peak Signal-to-Noise Ratio | 像素级重建质量 | ❌ 越高越好 |
| **SSIM** | Structural Similarity | 结构相似性 | ❌ 越高越好 |

### 2.2 FID/FVD 参考阈值

> 以下为文献参考范围，非 Cosmos Predict 2.5 的保证值。实际值依赖于训练数据质量和数量。

| 指标 | 优秀 | 良好 | 可接受 | 需改进 |
|------|------|------|--------|--------|
| **FID** | < 10 | 10 - 30 | 30 - 60 | > 60 |
| **FVD** | < 100 | 100 - 300 | 300 - 700 | > 700 |
| **IS** | > 50 | 20 - 50 | 10 - 20 | < 10 |

### 2.3 计算命令

```bash
# FVD 计算 (参考 cosmos-cookbook 评估脚本)
python evaluate.py \
    --real-videos datasets/eval/real_videos/ \
    --generated-videos outputs/trajectories/filtered/ \
    --metrics fvd fid \
    --batch-size 16

# 输出示例:
# FVD: 245.3
# FID: 28.7
# IS:  35.2
```

## 3. Critic 物理合理性指标

### 3.1 5 分制评分标准

```
┌────────┬───────────────────────────────────────────────┐
│  得分   │ 描述                                          │
├────────┼───────────────────────────────────────────────┤
│ 5 分    │ 完美物理 — 轨迹完全遵循物理定律，无任何不一致      │
│ 4 分    │ 良好物理 — 大部分正确，仅有微小可忽略缺陷          │
│ 3 分    │ 一般物理 — 大体符合，但存在明显不一致              │
│ 2 分    │ 较差物理 — 少数元素正确，多数存在违反              │
│ 1 分    │ 很差物理 — 完全不符合物理常识，不可用              │
└────────┴───────────────────────────────────────────────┘
```

### 3.2 零售场景评分示例

| 场景 | 描述 | 预期评分 | 常见缺陷 |
|------|------|---------|---------|
| ✅ 正确抓取 | 机械臂平稳抓取麦片盒，放入购物车 | 4-5 | — |
| ⚠️ 穿透 | 机械爪穿透商品表面 | 2-3 | 物体交互 |
| ⚠️ 悬浮 | 商品在放入购物车前悬停 | 2-3 | 运动与力 |
| ⚠️ 形变 | 抓取时商品异常拉伸 | 1-2 | 物体行为 |
| ❌ 失败抓取 | 商品滑落、碰撞货架后反弹异常 | 1 | 多种 |

### 3.3 Critic 评估指标

| 指标 | 公式 | 说明 |
|------|------|------|
| **Accuracy** | 正确预测数 / 总样本数 | 二值化 (阈值分割) 准确率 |
| **Spearman ρ** | 秩相关系数 | 评分排序质量 |
| **Pearson r** | 线性相关系数 | 评分线性相关 |
| **MAE** | `|pred - true|` 均值 | 平均绝对误差 |

### 3.4 VideoPhy-2 基准结果

> 以下为 NVIDIA 官方报告数据，参见 [Reason 2 技术报告](https://arxiv.org/abs/2504.06036)

| 模型 | 零样本准确率 | SFT 后准确率 | 说明 |
|------|-------------|-------------|------|
| **Cosmos Reason 2 (8B)** | ~65% | ~80%+ | 当前推荐 ✅ |
| Cosmos Reason 1 (7B) | ~40% | ~55% | 旧版本 |
| GPT-4V (零样本) | ~30% | N/A | 通用 VLM 对比 |
| 人类基准 | ~92% | N/A | 人类水平上限 |

## 5. 零售场景专项评估

### 5.1 评估检查表

| 评估项 | 方法 | 通过标准 |
|--------|------|---------|
| 商品识别准确率 | 人工 / CLIP 对比 | ≥ 90% 商品被正确生成 |
| 抓取动作连贯性 | Critic 连续性评分 | 帧间无跳变 |
| 放置自然度 | Critic 重力行为评分 | 商品自然下落至目标位置 |
| 场景多样性覆盖 | 统计商品/货架/视角组合 | ≥ 80% 组合被覆盖 |
| 轨迹成功率 | 人工审核 | ≥ 70% 轨迹可直接用于训练 |

### 5.2 领域特定评分维度

```
零售场景 Critic 重点评估维度
══════════════════════════════════

1. 抓取稳定性
   - 商品是否在机械爪中保持稳定
   - 是否有滑落或异常抖动

2. 商品完整性
   - 刚性商品不变形（盒子、罐子）
   - 柔性商品形变合理（袋子）

3. 空间合理性
   - 机械臂不穿透货架
   - 商品不穿过购物车/购物篮底部

4. 时序协调
   - 抓取-移动-放置三阶段连贯
   - 速度变化自然（加速 → 匀速 → 减速）
```

## 6. 评估流程

```
完整评估流程
═══════════════════════════════════════════════════

Step 1: 生成测试集轨迹
  torchrun inference.py -i eval_batch.jsonl -o eval_outputs/ ...

Step 2: Critic 评分
  uv run inference_videophy2.py --video-dir eval_outputs/ ...

Step 3: 计算视频质量指标
  python evaluate.py --real-videos ground_truth/ --generated eval_outputs/ ...

Step 4: 计算 Critic 指标
  python compute_critic_metrics.py --predictions critic_scores/ --labels human_labels/

Step 5: 综合分析
  → 生成评估报告 (本文件)
```

## 7. 迭代改进指南

| 观察 | 诊断 | 改进措施 |
|------|------|---------|
| FID/FVD 偏高 | 生成质量不足 | 增加训练数据、提高分辨率、延长训练 |
| Critic 通过率 < 30% | 物理合理性差 | 增加 N 值、检查训练数据质量 |
| Critic 准确率 < 理想值 | Critic 评估不准 | 对 Critic 做 SFT 微调 |
| 某些商品评分偏低 | 模型未见该商品 | 增加对应商品训练数据 |
| 评分方差大 (同场景不同 seed) | 模型不稳定 | 增大 guidance 或 N 值 |
