# 系统架构

> **项目**: RDL-Dreams — 基于 Cosmos GR00T-Dreams 的商超零售机器人抓取轨迹生成  
> **主方案**: [../README.md](../README.md) | **官方菜谱**: [../../Dev_book.md](../../Dev_book.md)

## 1. 总体架构

RDL-Dreams 采用 **世界基础模型 (WFM) + 视觉语言模型 (VLM) Critic** 的双模型架构，实现从单张图像 + 语言指令 → 高质量合成抓取轨迹的端到端管线。

```
                            RDL-Dreams 系统架构
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      
│  ┌──────────┐    ┌───────────────┐    ┌───────────────┐              
│   输入                世界模型            Critic 评判                 
│                                                                 
│   📷 初始帧   ->      Cosmos       ->      Cosmos       -> ✅/❌   
│   📝 Prompt         Predict 2.5            Reason 2                    
│                     Video2World           (1-5 分制)                 
│  └──────────┘    └───────────────┘    └───────────────┘             
│                         │                      │                     
│                         ▼                      ▼                     
│                  ┌──────────────┐    ┌───────────────┐              
│                  │ 后训练        │    │ 零样本 / SFT                
│                  │ (GR1+零售数据) │    │ (VideoPhy-2)             
│                  └──────────────┘    └───────────────┘              
│                                                                      
│  数据平面:                                                            
│  ┌──────────┐    ┌───────────┐    ┌──────────┐    ┌──────────┐      
│     仿真器     →   Transfer  │ →  │ Curator    →    训练集      
│    (Isaac)           2.5       │    │ 策展                     
│  └──────────┘    └───────────┘    └──────────┘    └──────────┘      
│                                                                      
└──────────────────────────────────────────────────────────────────────┘
```

## 2. 组件说明

### 2.1 核心模型

| 组件 | 模型 | 参数量 | 角色 |
|------|------|--------|------|
| **世界模型** | Cosmos Predict 2.5 Video2World | 2B (默认) / 14B (可选) | 接收 image + prompt → 生成未来帧视频（轨迹） |
| **Critic** | Cosmos Reason 2 | 8B | 评估生成视频的物理合理性，输出 1-5 分 |

### 2.2 数据工具链

| 组件 | 用途 | 是否必选 |
|------|------|---------|
| **Isaac Sim / MuJoCo** | 生成商超货架抓取合成视频 | ✅ 零售适配核心 |
| **Cosmos Transfer 2.5** | Sim2Real 风格迁移（Edge Control） | 推荐 |
| **Cosmos Curator** | 视频策展：分割→转码→字幕→过滤→去重 | 推荐 |

## 3. 数据流

```
Phase 1: 数据准备
────────────────────────────────────────────────────────────
仿真器                    Transfer 2.5           Curator
┌──────────┐  合成视频   ┌──────────┐  增强视频  ┌──────────┐  策展数据
│ Isaac    │──────────→│ Sim2Real │─────────→│ 分割/字幕 │─────────→ 训练集
│ Sim      │           │ (Edge)   │          │ 过滤/去重 │
└──────────┘           └──────────┘          └──────────┘
                              │
GR1-100 (HuggingFace) ────────┴──────────────────────────→ 训练集
  (基线桌面操作数据)

Phase 2: 后训练
────────────────────────────────────────────────────────────
训练集 ──→ Predict 2.5 Post-Training ──→ DCP 检查点 ──→ .pt 转换

Phase 3: 轨迹生成
────────────────────────────────────────────────────────────
Prompt + 初始帧 ──→ 微调后 Predict 2.5 ──→ N 条候选轨迹视频

Phase 4: Critic 筛选
────────────────────────────────────────────────────────────
N 条候选 ──→ Reason 2 逐条评分 (1-5) ──→ 筛选 Score ≥ 4 ──→ 高质量轨迹集
```

| 阶段 | 目录 | 输入 | 输出 |

## 5. 关键设计决策

### 5.1 为什么用双模型架构

- **Predict 2.5** 擅长生成：从单帧图像预测未来多帧，天然适合"给定当前货架状态 → 生成完整抓取过程"
- **Reason 2** 擅长判别：评估物理合理性（重力/碰撞/因果），弥补生成模型可能出现的物理违反
- 两者通过 **Best-of-N 拒绝采样** 解耦协作：Predict 生成 N 个候选 → Reason 筛选最优

### 5.2 为什么用 Video2World 而非 Text2Image

- Video2World 接收**前几帧视频 + 文本** → 生成后续视频
- 对于轨迹生成，初始帧（商品 + 货架 + 机械臂初始位姿）是必需的视觉上下文
- 纯文本无法精确描述机械臂位姿和商品空间关系

### 5.3 为什么 Critic 默认零样本

- Reason 2 零样本已在 VideoPhy-2 上取得 +25% 准确率提升（vs Reason 1）
- 零样本可直接使用，降低入门门槛
- SFT 微调作为可选项，在零样本效果不足时启用（详见 `training.md`）
